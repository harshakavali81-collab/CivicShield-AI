# Dataset policy

No real weather observations or individual incident reports are committed.

## Training CSV contract

A legally obtained, properly labeled observation file must contain:

| Column | Type | Description |
|---|---|---|
| observed_at | ISO-8601 UTC timestamp | Date/time the **features would have been known** |
| rainfall_24h_mm | numeric 0+ | Rainfall measured over prior 24 hours |
| temperature_c | numeric | Air temperature |
| humidity_pct | numeric 0–100 | Relative humidity |
| risk_label | binary 0 or 1 | Independently derived, documented ground truth (NOT generated by thresholds used as features) |

Labels require domain definition, geographical scope, careful temporal joins and genuine observed outcomes. Do NOT label your data using the same rainfall threshold used by a model and claim independent prediction. This is demonstration code, not a validated model. Use chronological and geographic holdouts; audit gaps and missingness; document class imbalance and uncertainty.

In production, obtain license permissions for every data provider and protect personal locations and narratives. Keep data under gitignored \`data/raw/\` and \`data/processed/\`.
